🧬 进化建议

🔴 高优先级

1. 配置 Provider 降级/fallback 机制
今天同时出现 429 RateLimitError 和 APITimeoutError，deepseek-v4-flash 通过 TokenHub 的连通性持续恶化。建议在 config.yaml 中配置 fallback model：当主模型 429/超时时自动切换到一个更便宜的备用模型（如 deepseek-v4-base 或 GPT-4o-mini）。
2. Weixin 推送策略重审
Weixin 错误连续 3 天回升（10→16→26），rate_limit 类别从 120 升至 148。会话超时 + 重试组合严重影响推送可靠性。建议切断 Weixin 作为 cron job 的交付渠道，或加入频控限流器。
3. 安全审批白名单
tool_executor 错误 52 条中 majority 来自 pending_approval 阻塞。将 scripts/ 目录和 /tmp/ 下的已知脚本加入安全白名单可减少 60%+ 的 tool_executor 错误。

🟡 中优先级

4. SessionDB 兼容修复
self_scan.py 报 `'SessionDB' object has no attribute 'list_sessions'`，sessions 数据持续不可用。需适配 Hermes 版本的 SessionDB API。
5. 新增 Agent 安全监控参考
今天 arXiv 收录的 Stateful Online Monitoring 论文与 Hermes 的安全架构直接相关，建议纳入安全设计评审参考。
