🧬 进化建议

🔴 高优先级

1. tool_executor 安全审批白名单 — 紧急
tool_executor 错误连续 5 期恶化（19→25→36→52→67），累计 +253%。本期 06-03 08:06-08:09 密集出现 6 次 pending_approval 阻塞。将 ~/.hermes/scripts/ 和 /tmp/ 下的已知脚本路径加入安全白名单可减少 60%+ 的 tool_executor 错误。这是目前最大且唯一加速恶化的风险。
2. Provider 降级/fallback 机制
API 问题连续 5 期出现（P3-P7），deepseek-v4-flash via TokenHub 的稳定性无改善。配置 secondary_model 为 deepseek-v4-base 或 GPT-4o-mini 可确保主模型限频/超时时 cron job 持续运行。
3. Weixin 推送策略优化
虽然 Weixin 错误降至 151（-6%），仍是最高的单一组件。每日错误从 06-02 的 32 回落至 06-03 的 20，但均值仍在 20+。持续推动 GitHub Pages 作为主要交付渠道以减少 Weixin 依赖。

🟡 中优先级

4. knowledge_ingest.py 增加 arXiv 退避重试
P6 成功、P7 失败的间歇性模式已确认。API 在 ~70% 时间内可用。建议：① 指数退避重试最多 3 次；② 每次请求记录 HTTP 状态码；③ 添加 arXiv Sanity Lite (arxiv-sanity-lite.com) 作为备选。
5. SessionDB 兼容修复
self_scan.py 报 'SessionDB' object has no attribute 'list_sessions'，sessions 数据已连续 7 期不可用。需适配当前 Hermes 版本的 SessionDB API。
6. 移除未配置的 Discord 适配器
54 条/天的无用错误（27 Opus codec + 27 No bot token），已连续 7 期点名。从 config.yaml 移除 discord_platform 是 5 分钟可解决的"低挂果实"。

🟢 低优先级

7. 关注 Code Agent 生态演进
微软 MAI-Code-1-Flash 今日发布（375 points），代码生成模型生态竞争加剧。Nvidia VRAM swap（86 points）对本地 GPU 部署有直接帮助。Stanford AI 法律研究（40 points）展示 AI 专业能力突破边界。
