A8 个技能 slug 首字母 A

adaptyvA
一句话定位蛋白质实验设计与提交
功能让 agent 能通过 Adaptyv Bio Foundry API 和 Python SDK 进行蛋白质实验设计、提交与结果检索。可浏览靶点、估算成本、创建并提交结合/筛选类实验(如 BLI/SPR、热稳定性测定),并在后续阶段取回实验表征结果;当代码中出现 adaptyv、FoundryClient 等导入时也会触发。
适用场景蛋白工程研究者想把候选蛋白序列送去平台做实验表征、或希望脚本化批量提交与跟踪实验时使用。
案例用户说:『用 Adaptyv 帮我提交这 3 条序列做蛋白结合实验并估算成本』→ agent 通过 Foundry API/SDK 浏览可用靶点、估算费用、创建并提交实验,稍后检索并汇报结果。

aeonA
一句话定位时序机器学习算法库
功能让 agent 能处理时间序列机器学习任务,包括分类、回归、聚类、预测、异常检测、分段与相似性搜索。面向单变量/多变量时序数据,提供超越常规 ML 算法的专用方法,API 与 scikit-learn 兼容。
适用场景分析随时间采样的数据(传感器序列、时间索引观测)且需要专门时序算法的人。
案例用户说:『用这组传感器时序数据做分类并预测未来 7 天』→ agent 加载数据、训练 aeon 时序分类器,再做预测并评估。

analytical-method-validationA
一句话定位分析方法验证规划
功能让 agent 能依据 ICH Q2(R2)/Q14、USP、ICH M10、CLSI EP、ISO/IEC 17025 等框架规划、执行并记录分析方法的验证、确认与转移。覆盖 HPLC、LC-MS/MS、GC、CE、ICP-MS、溶出、qNMR、qPCR、NIR、配体结合/细胞实验等方法,评估线性、报告范围、准确度与精密度等是否满足预期用途。
适用场景制药与质检实验室需判断分析方法是否适合其用途、或编写验证方案与接受标准时使用。
案例用户说:『为这个 LC-MS/MS 方法按 ICH Q2(R2) 写一份验证方案』→ agent 选定框架与所需特性、生成协议并填入线性/精密度等接受标准。
