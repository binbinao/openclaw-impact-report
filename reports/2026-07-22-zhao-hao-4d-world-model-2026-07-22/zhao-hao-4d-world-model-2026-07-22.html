核心论点拆解

论点一：什么是"真正的世界模型"？

世界模型最核心的就是刻画世界的变化。无论是生成视频、三维场景，还是在其中训练机器人、做自动驾驶，本质上都是在刻画世界的变化。
赵昊的定义（State t → State t+1）：世界模型不限定形式，可以是语言模型的 Token 状态变化、AlphaGo 的棋盘向量、JEPA 的一维表征、2D 视频 Token、3D/4D 表征——只要能刻画从 State t 到 State t+1 的转换，都是世界模型。
反方观点（视频派）：DeepMind 的 Genie 3（2025-08-05 发布）已经能实时生成 24fps、720p、可探索的交互世界，保持数分钟一致性——它没有显式 4D 表征，但能完成赵昊所谓的"刻画变化"任务。这恰恰说明显式几何表征不是世界模型的必要条件。

论点二：为什么必须是 4D？

如果采用一维或二维的 Token，天然缺乏四维物理世界所需的表征，包括物理属性和光学属性，因此很难真正刻画世界的变化。
赵昊的论证链：
  1. 表征维度决定能力上限。1D Token 只能盲目映射；2D 视频生成无法理解空间关系；3D 无法理解"快快的""轻轻的"这种奖励信号。
  2. 可解释性。神经网络本身可解释性差，1D/2D 表征出错了"束手无策"，4D 表征可以诊断具体哪一帧的几何/力学属性不对。
  3. 物理属性必须编码。世界模型的物理属性分四类：热学、电磁学、光学、力学。赵昊团队现阶段聚焦力学 + 光学——分别对应自动驾驶/机器人动力学和视觉真实性。
  4. 3D + 时间 ≠ 4D。纯三维加时间轴只是 3.5D。每帧之间没有通过光学和力学建立联系——"每一帧都只是一个独立的三维场景"。真正的 4D 必须把杨氏模量、密度、动量、受力都刻画进去。

论点三：4D 与 2D 的关系——"重模型 vs 轻模型"

我预言，四维世界模型未来将会是一个大模型，而二维的模型可能是从 4D 模型中提取出来的一个小模型。所以，它们之间的关系是：我们的 4D 世界模型是"重"模型，而 JEPA 这样的是"轻"模型。
赵昊的核心预言：
  • 4D 是大模型，2D 是提取出来的子模型。类似 GPT 把所有知识囊括后再降维到子任务。
  • "我们可以降维，但它们无法升维"。一旦 4D 路线走通，2D 路线可以复用成果；但 2D 路线即便成功也无法替代 4D。
  • 几何先验不是"拐杖"。不是"数据和模型不够才需要"，而是"数据和模型够了也需要"——纯 2D 大模型要训练，必须用 4D 模型生成的数据。
业内对比视角：这条论断与 Yann LeCun 的 JEPA（联合嵌入预测架构）路线形成对峙——LeCun 认为非生成式、自监督的 JEPA 才是通往 AGI 的路径，世界模型不需要显式生成像素。赵昊的观点更接近 3D/4D 显式表征派，介于 LeCun 与视频生成派之间。

论点四：自动驾驶世界模型还没量产的原因

之前自动驾驶的范式相对没有收敛。所以，之前大家也很难让做模型的人用一个统一的方法去 scale up 它。
赵昊给出的解释（双因）：
  1. 产业周期原因。过去三年（2023 MARS → 2026）自动驾驶范式正在收敛，到 2026 才到了"持续数据 + 算力 + 工程团队 + 客户迭代"的阶段。
  2. L2.99 卡点。自动驾驶"卡"在 L2.99，必须有大规模量产的世界模型才能推到 L4。
对比印证：特斯拉 2025 年 10 月公开"神经世界模拟器"，定位是"进入量产系统训练与闭环评测流程的模型"——这是赵昊所谓"自动驾驶范式收敛"的具体证据。

论点五：商业化路径——学院派的真正优势

世界上大概有产品型、平台型和技术型三类公司，AI 显然属于技术型。像 GPT 或语言模型，必然是 OpenAI 这样的全明星科学家团队才能做出来。
赵昊的产业分类框架：
类型代表核心竞争力
产品型腾讯（微信）、字节（抖音）产品体验与人性拿捏
平台型阿里管理与生态
技术型OpenAI、特斯拉 FSD全明星科学家 + 技术突破
潜在反例：把 AI 单纯归为"技术型"忽略了应用层——比如法律、医疗、教育等垂直领域 AI 落地，恰恰需要产品型公司的场景理解和渠道能力。Anthropic 的 Claude 是技术型，但它的企业渗透速度未必比 OpenAI 快。

论点六：起步阶段最稀缺的数据

仿真数据之所以重要，是因为几何和速度信息无法通过人工标注获得，而仿真数据中的几何、速度信息是绝对精准的。
数据策略矩阵：
数据类型优势局限
真实数据无 Sim-to-Real 差距几何/速度标注不精准
仿真数据几何/速度绝对精准存在 Sim-to-Real 差距
接触力学仿真灵巧手等高密度动态场景最难的子任务
赵昊团队 RTX-IPC 仿真较 StiffGIPC 实现端到端加速 1.7 倍，面向灵巧手等高密度动态接触场景提供底层计算能力。

关键洞察：4D 派的论点强在哪里？弱在哪里？

强的地方

  • 可解释性优势是真实的。4D 表征可以诊断"这一帧的力学不对"，纯视频模型确实做不到——这是工程上重要的诊断能力。
  • 团队执行力强。三年内密集产出 3 篇 Best Paper + 多篇顶会，覆盖 3D 生成、机器人、自动驾驶三条线——执行力本身就是论证。
  • 商业化路径清晰。明确说"已经在 L2-L2.99 有工业合作案例"——比纯学院派的"未来可期"更可信。
  • "降维打击"框架有说服力。如果 4D 真能成为"大模型"，2D 提取出的轻模型确实可以无处不在——这是规模法则的合理外推。

弱的地方

  • "1 分钟视频一致性"短板。赵昊承认"无论你用哪种方法，还是很难突破生成超过 1 分钟的视频"——这恰好是 Genie 3 已经做到的事（数分钟一致性）。
  • "跨行业基模可能不对"。他自己承认："唯一一个可能是错的，就是跨行业基模可能不对，在未来三年内大家也许会判断它实在是太难做了。"
  • 缺少真实数据 benchmark。目前"我们确实暂时还没有能力去做这么大规模的评测"——这是诚实但也是软肋。
  • 奖励机制设计模糊。提到"需要独立的价值模型"但没说具体怎么做——这是 RL 与世界模型结合的关键未解问题。
  • "纯 2D 大模型需要 4D 数据"的因果链未验证。这是核心商业论断（"4D 是数据源头"），但目前没有论文/实验支撑。

对工业 AI/自动驾驶行业的启示

  1. L2 → L4 的卡点是世界模型。赵昊明确说"自动驾驶要消耗很多算力、很多卡，还有视频生成和编程，这是三个已经比较 solid 的 workload"——这三个是 2026-2028 真正能收钱的 AI 方向。
  2. 国内自动驾驶公司路径分歧。赵昊"现在自动驾驶已经进入了 4D 世界模型的新时代"——理想/蔚来/小鹏/比亚迪等是否有类似路线？他们的世界模型团队规模？
  3. 接触力学仿真是稀缺能力。RTX-IPC 1.7× 加速 + 灵巧手落地——这块对国产机器人（宇树、智元、银河通用）是关键基础设施。
  4. 学院派商业化的窗口。赵昊的"技术型公司"判断意味着清华 AIR / 上交 / 北大等院校的 AI 团队正在迎来资本与产业合作机会。

局限性

必须如实标注：
  • 赵昊是物理 AI 4D 路线的强烈倡导者，本访谈必然带有立场偏向——反方观点（Genie 3、JEPA 派）需读者自行检索补充。
  • "行业最大质疑 = 模型误差积累"——赵昊承认这是事实，但没给出量化答案。
