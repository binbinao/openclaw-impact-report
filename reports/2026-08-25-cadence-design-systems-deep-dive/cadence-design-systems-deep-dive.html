TL;DR · 一句话 + 三条洞察

Cadence 是全球三大 EDA 厂商之一（与 Synopsys、Siemens EDA 并列），业务从 IC 设计、PCB 与封装到多物理场系统仿真与 AI 驱动 EDA 全栈覆盖。

  • 产品矩阵：13 大类 / ~50 核心 SKU，从工厂使用视角压缩为「前端 → 后端 → 物理签收 → 封装/3D-IC → PCB/系统」五段链路。
  • 代工渗透：TSMC（OIP 创始 EDA 联盟）、Samsung Foundry（2nm + 3D-IC）、Intel Foundry（18A/18A-P/14A）、Rapidus（2nm GAA）、GF（primary vendor）—— 五大代工全部认证。
  • 2025-2026 战略转折：Cerebrus → Cerebrus AI Studio → InnoStack AI Super Agent 三级跳，配合三大代工的 AI flow 发布。AI EDA 赛道与 Synopsys DSO.ai 的竞争进入白热化。

关键产品注解

Cerebrus AI Studio

2026 年发布，把 Cerebrus + agentic AI 的 studio 版——允许多 agent 协同调试、实现、signoff、ECO、closure 自动化。

Integrity 3D-IC Platform

跨 die + interposer + substrate + package 统一数据库与 co-design 环境。是 TSMC 3DFabric、Samsung Foundry 2nm/3D-IC 的 reference flow 基础。

Innovus+ Implementation

P&R 旗舰，2025-2026 与 Innovus+ AI Assistant 整合 Cerebrus 提供 AI 推荐。Intel 18A 节点已通过认证。

Palladium Z2 Emulation

ASIC 硬件仿真平台，10 亿门 SoC 验证。Z2 性能为 Z1 的 1.5×、容量 2×。

Spectre Platform

SPICE-class 仿真器跨 CPU/GPU 分布式。Spectre X / FX / RF / Photonics / AMS 五大模块。

Allegro X AI Advanced Substrate Router

25.1 版本（2025-10）新增，专门优化高密度 single + multi-chip package 的 routing——EMS 厂的关键工具。

SECTION 03

Samsung Foundry · Intel Foundry · Rapidus

Samsung Foundry（2nm + 3D-IC）

2026-05-28 公告：Cadence 与 Samsung Foundry 深化 2nm + 3D-IC 合作。Integrity 3D-IC Platform 是 Samsung Foundry differentiated reference flow 的基础。2019 年已通过 Samsung 7LPP 3D-IC 工艺认证。

Intel Foundry（18A / 18A-P / 14A）

2024-02-21 公告：Cadence 数字 + 定制/模拟 + 设计 IP 全栈认证。Digital full flow 含 Genus / Innovus / Quantus / Tempus / Pegasus / Liberate / Voltus；Custom flow 含 Virtuoso Studio / Spectre / Voltus-XFi。设计 IP 含 PCIe 6.0 / CXL / LPDDR5X 8533Mbps / UCIe / 112G SerDes。Intel VP Rahul Goyal 称 Cadence 为 "an indispensable partner"。

Rapidus（2nm GAA + Agentic AI）

2026-07-16 公告：Rapidus + Cadence 合作 Agentic AI for Advanced SoC Design，针对 Rapidus 2nm GAA 工艺——Rapidus 官网 IR + Cadence IR + Tokyo Tribune + 3D InCites 四源交叉确认。

GLOBALFOUNDRIES

Cadence 被 GF 选为 Primary EDA Tool Vendor。GF 12LP+ / 22FDX / 9HP 等工艺基于 Cadence flow 提供 PDK。

EMS 厂落地证据

  • Routing + tuning 所需工程资源减少 75%
  • 引述方：Sky Huang, Pegatron 计算机辅助工程副总监
  • 二源：Cadence 官方 Success Story + EMA Design Automation PDF

⚠ Flex / Jabil / Foxconn / BYD Electronic / Lite-On / Quanta

无公开 PR——EMS 厂惯例不公开 EDA 选用。Cadence Allegro X 在 EMS 行业的事实标准地位由四重间接证据充分：

  1. 官方 Success Story（Pegatron 等少数案例授权发布）
  2. Allegro X 在 PCB 设计市场长期市占率第一
  3. 全球 2,500+ 制造商 Ultra Librarian 生态（1,800 万验证符号）
  4. 中国/台湾/欧美分销网络齐备

OrCAD X 中小用户生态（G 维度）

OrCAD X 原生集成 Ultra Librarian（现已并入 Cadence），即时访问 超过 1,800 万个验证符号、footprint 和 3D 模型，来自 2,500+ 制造商；每个模型通过 30+ 验证测试，按 IPC / ANSI 标准构建。同时每个器件可实时显示价格、库存、Lead Time、合规数据，并直接提交 BOM 给 Mouser / Digi-Key / Arrow / Avnet 等分销商采购。

SECTION 06

IDM 内部使用 + AI EDA 战略

Intel

Palladium Z2 硬件仿真平台是 Intel 内部验证 billion-gate SoC（数据中心、CPU、GPU）的标配。

Samsung

Cadence Integrity 3D-IC + Pegasus Verification 做 2nm GAA 与 SF2 节点的 sign-off。

Micron / SK Hynix

HBM4 内存 sign-off 用 Sigrity/Integrity（TSMC-COUPE 14.4G LPDDR6/5X 在 Cadence 设计 IP 中已硅验证）。

AI EDA 战略

Cerebrus（2021）→ Cerebrus AI Studio（2026）→ InnoStack AI Super Agent（2026） 三级跳。PPA 数据：功耗↓20%+、面积↓10%+、频率↑10%+。与 Synopsys DSO.ai / Siemens Solido 进入正面竞争。

CadenceLIVE 2025

CEO Anirudh Devgan 主题演讲发布 Millennium M2000 超算/EDA 硬件平台。同期 Anirudh 与 NVIDIA Jensen Huang、Lip-Bu Tan fireside chat。

光子工厂

Spectre Photonics + Clarity 3D Solver 是硅光芯片设计主流工具，被 Lightmatter（AIM Photonics 工艺）等光子芯片公司采用。

SECTION 08

中国市场 + 出口管制案

合规事件

2025 年 7 月，Cadence 因 2015-2021 向中国 NUDT（国防科技大学） 销售 EDA 软件，被美国司法部判罚 1.4 亿美元（3 年公司缓刑）。事件涉及员工使用 "Central South CAD Center (CSCC)" 和 "Phytium Technology" 作为中介规避实体清单。Cadence 中国区员工 800+（上海亚太总部 + 北京/深圳）。

中国市场布局

  • 1992 年进入中国大陆，1994 年北京人民大会堂发布会
  • 2008 年上海设亚太总部
  • 2025-04：收购 Arm Artisan 基础 IP 业务
  • 2025-07：推出 LPDDR6/5X 14.4Gbps 内存 IP
  • 2025-11：联合 NVIDIA Apollo 系列 AI 物理模型 + Warp 框架
  • 高校合作：清华、北大、复旦、上交、同济、西电（2023-05 西电-Cadence EDA 联合实验室）
  • 中国区代理：上海图元软件技术有限公司
