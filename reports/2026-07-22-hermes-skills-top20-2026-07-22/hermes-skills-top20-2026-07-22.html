关键洞察

1. 本地比官方更广。本地 131 vs 官方 72，差距 59 个技能来自 profile 私有 + 第三方贡献（如 third-party-skill-installer、diagramming、ecc-imports、eight-vows 等）。
2. 官方偏内置工具。apple / hermes-desktop-plugins / hermes-themes / yuanbao / dogfood 这 5 类官方专属，本地不需要——它们是 Hermes Agent 内核插件或主题。
3. 本地补足了 devops / gaming / career。这些分类不在官方仓库目录里，但本地有 7+2+1 个技能，说明用户场景更偏运维和工业落地。
4. creative 与 productivity 是生态共识。两边热度前两名相同，证明这两个领域是 Hermes Agent 用户的共同刚需。
