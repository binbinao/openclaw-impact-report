Scania IDPS 潜在合作/收购标的调研

背景：Scania 发布车载 IDPS（QNX 部署 / HIDS+NIDS / VSOC / 10min 合规）RFP，正式 PD 预计 7/21 发出。
腾讯云当前无可直接投标的车载 IDPS 产品。本报告筛选三家标的企业评估合作/收购可行性。

前置结论：三家都支持 QNX 部署和 HIDS+NIDS+VSOC 全栈能力，技术上均能满足 Scania 核心要求。差异在于 量产规模、海外部署经验、白盒交付能力和收购可行性。

二、产品能力对标 Scania RFP

Scania RFP 要求 为辰信安 云驰未来 PlaxidityX
① QNX 部署 ✅ 明确支持：适配 QNX / Android / Linux，无需改代码，直接编译移植（CSDN/51CTO） ✅ 覆盖兼容：QNX / Android / Linux，中间件 SDK 模式（EET-China） ✅ 原生支持：eBPF 技术深度监控 QNX 内核（官网）
② HIDS + NIDS ✅ HIDS + NIDS + CANIDS：覆盖车载以太网 / CAN 网络 / 主机系统，原子化服务适配 SOA 架构（官网） ✅ HIDS + NIDS + CANIDS：全栈 IDPS，支持 CAN/CANFD/Ethernet（官网） ✅ HIDS + NIDS：IDPX agent 支持 eBPF 深度检测（官网）
③ Log & Event 聚合 ✅：CGW / TBOX / IVI 分布式探针 → 统一 VSOC 上报（官网） ✅：CNCU 中央网络控制器 + IDPS SDK 完成车端聚合（官网） ✅：IDXM Manager 统一日志汇聚（官网）
④ VSOC 对接 ✅ deCORE VSOC：AWS 云部署，态势感知 + 联动响应，3家 OEM 通过 VTA 目击测试（官网/AWS） ✅ inVSOC：AWS IoT Core 架构，已为某新能源车企部署欧洲 VSOC（官网/AWS） ✅：自有 VSOC 或对接第三方（官网）
⑤ 10min 合规窗口 ✅ 常态化支持：200万+车辆在线运营经验，满足 UN R155 持续性监测要求（中金在线/官网） ✅ 支持：UN R155 / ISO 21434 合规，海外多地区部署经验（官网） ✅ 支持：UN R155 / ISO 21434，全球 OEM 合规案例（官网）
⑥ 白盒交付 ⚠️ 部分白盒：IDPS 策略可配置，VSOC 提供 API，但 未见"全源码交付"承诺 ⚠️ 部分白盒：安全网关 SDK + 中间件可定制，同样 未见全源码承诺 ✅ 明确白盒：IDPX 规则透明、可自定义策略，支持 white-box 模式（官网）
两阶段交付 ✅：100+ 车型量产经验，分阶段 SOP 交付成熟（官网） ✅：已服务 OEM + L4 双线客户，工程化能力强（36氪） ✅：全球 Tier1 合作经验，项目管理成熟
关键发现：为辰信安和云驰未来技术上 6/6 覆盖 Scania 需求（白盒交付为"部分支持"需要进一步确认），PlaxidityX 在白盒交付和 QNX 深度支持上有优势。但对腾讯而言，国内两家是更现实的合作/收购对象。

五、推荐路径与行动建议

综合技术匹配度、收购可行性、Scania 需求紧迫度（7/21 正式 PD 发出），给出三条路径：

推荐 ⭐

路径 A：战略合作 + 联合投标

短期最可行，可赶上 Scania 7/21 RFP

  1. 选择 为辰信安 或 云驰未来 作为车端 IDPS 技术伙伴
  2. 腾讯提供云端 VSOC（替换 AWS）+ 威胁情报 + 合规咨询
  3. 联合响应 Scania RFP，以"双供应商"模式（腾讯云 + IDPS 伙伴）投标
  4. 对 Scania 口径："腾讯云车联网安全方案，整合中国领先的 IDPS 供应商"
第一选择：为辰信安 — 装机量/量产经验/海外VTA最强
第二选择：云驰未来 — BMW背书/TISAX/创始人更有出售意愿
考虑

路径 B：收购云驰未来

中长期战略动作，建立自有车载安全能力

  1. 启动与金沙江创投/曾剑隽的初步接触
  2. 估值 ¥3-6亿 RMB，对腾讯属于可控规模
  3. 收购后可形成"腾讯云安全 × 车载 IDPS"独特定位
  4. 时间线：至少 6-12 个月，赶不上当前 Scania 标
⚠ 风险：创始人阿里系背景可能对大厂收购有戒心；团队整合可能有人才流失
高风险

路径 C：自研 IDPS

利用科恩实验室自研，但时间完全不够

  1. 科恩实验室在汽车攻防研究有积累（IEEE S&P 2024 顶会论文）
  2. 但 QNX agent 从零开发 + 量产验证 ≈ 18-24 个月
  3. 完全不可能赶上 Scania Phase 1（2026年底）
❌ 不推荐 — 除非放弃本次 Scania 标，作为长期战略布局
