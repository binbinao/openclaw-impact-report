关键洞察

1. 头部两个独占鳌头。comfyui（19）和 huggingface-hub（17）评分断崖式领先——这两类覆盖了"AI 内容生成"和"AI 模型获取"两大最刚需场景，是 Hermes Agent 生态的核心枢纽。
2. apple 系列是 macOS 专属。apple-notes（13）和 imessage（4）占了官方苹果生态的全部 4 个技能，反映 Hermes Agent 在 macOS 桌面端的覆盖深度。
3. Top 20 分类分布：productivity 5 个、creative 3 个、github 3 个、mlops 2 个、research 2 个、note-taking 1 个、media 2 个、apple 2 个——通用办公 + 创意生成 + GitHub 工作流占绝对主导。
4. 长尾技能单一覆盖。19 个分类里有 12 个只有 1 个技能（computer-use、data-science、dogfood、email、hermes-desktop-plugins 等），说明 Hermes Agent 技能生态广度优先而非垂直深耕。

局限性

必须如实标注的不确定项：
  • 无下载量/星标数据。GitHub API 未认证限流，未抓取每个 SKILL.md 的 star / fork / 提交频率。"实用性强"是基于 description 字段的关键词启发式，不代表真实使用频率
  • 未覆盖子目录全树。递归深度受限，部分分类（如 mlops/、research/）的深层子目录可能还有遗漏，但单次扫描上限稳定在 64-67 之间
  • 不替代个人 Top 20。不同用户的刚需差异巨大（如苹果用户会推 apple 系列，开发者会推 github 系列）——官方视角不等于个人视角
