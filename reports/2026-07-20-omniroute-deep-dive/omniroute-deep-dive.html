五、安装方式

# 1. 安装 CLI
npm install -g omniroute    # Node.js 版
# 或 pip install omniroute  # Python 版

# 2. 一键配置（可脚本化）
omniroute setup --non-interactive

# 3. 测试连接
omniroute providers test-batch

# 4. 用本地端点替代原 API
# Base URL: http://localhost:<port>/v1
# API Key: 你设置的 INITIAL_PASSWORD

# 5. 配置 Claude Code
omniroute configure codex

关键环境变量：

  • INITIAL_PASSWORD — 初始密码
  • OMNIROUTE_BASE_PATH — 反向代理路径
  • OMNIROUTE_WS_BRIDGE_SECRET — WebSocket 桥密钥
  • OMNIROUTE_NO_SUDO — root-less 模式
