# 上海软信业《"十五五"规划》深度调研——对个人开发者与工业软件企业的双向影响

> **信源**：6 | **模式**：Deep Research (Pro) | **调研日期**：2026-08-12
> **报告版本**：v1.0 · Hermes Agent

---

## Bottom Line

2026 年 8 月 11 日，上海市经济和信息化委员会正式印发《上海市软件和信息服务业发展"十五五"规划》（**沪经信软〔2026〕471号**），明确到 **2030 年全市软信业规模力争达到 4 万亿元**、增加值突破 1.1 万亿元，**较 2025 年的 2.1 万亿元实现近 1 倍增长**[1]。**与"十四五"年均 15% 左右的实际增速相比，"十五五"隐含的复合增速需保持在 13.7% 左右**[2]，意味着上海已经不再追求规模翻倍的爆发式扩张，而是把重心明确放在 **AI 赋能、企业培育、产业空间布局和"软件即服务"商业模式重构**上。

对 **个人开发者**而言，规划首次在市级规划层面把 **Token、模型部署与再训练、Coding 平台、超级个体 / 一人公司 (OPC)** 写入政策语境[1]，并配套"算力券、模型券"等补贴工具[1]——这是国内省/市级规划里少有的"把开发者当成生产要素"的表述[6]。对 **工业软件企业**而言，规划把 **"AI+工业软件"百企百项、Coding 平台普及、CAD/CAE/EDA 底层攻关、工业软件中试验证平台、按效付费 (SaS) 模式** 作为五大具体抓手[1]，叠加 2026 年起"政府采购本国产品给予 20% 价格评审优惠"的全国性政策[5]——这是 2027 年前中国工业软件市场迈向 4200 亿元规模[5]的最大增量来源之一。

规划最值得警惕的两点是：**（1）"超大型平台企业"指标从 5 家增至 7 家**[1]——意味着流量进一步向头部集中，中小开发者可分得的 API 入口与场景资源会相对收紧；**（2）研发投入占比仅从 9.02% 微调至 ≥10%**[1]——对比北京、深圳、杭州同类规划的 12%~15% 目标，上海在 R&D 强度上偏保守，工业软件底层技术突破节奏会受投入约束。

## Key Findings

### 1. 规划本身：定位、指标与节奏

| 维度 | 2025 实际 / 基线 | 2030 目标 | 增量 |
|---|---|---|---|
| 产业规模 | 2.1 万亿元 | 4 万亿元（力争） | +1.9 万亿，~13.7% 隐含 CAGR |
| 信息传输、软件和信息技术服务业增加值 | 0.71 万亿元 | ≥1.1 万亿元 | +0.39 万亿 |
| 软件业研发投入占比 | 9.02% | ≥10% | +1pp |
| 新增软件著作权登记总量 | 112 万个 | 约 115 万个 | +3 万个 |
| 营收超百亿元企业 | 28 家 | 35 家 | +7 家 |
| 超大型平台企业 | 5 家 | 7 家 | +2 家 |
| 国家鼓励的重点软件企业占全国比重 | 10.6% | ≥13% | +2.4pp |
| 营收超千亿元产业基地 | 4 个 | 6 个 | +2 个 |

**八项指标全部为"预期性"**（非约束性），其中产业规模"力争"4 万亿[1]——这是 2020-2025 翻番基础上第一次明确"不再简单翻倍"，而是用"质量+结构"代替"纯规模"。

**十四五基准线（来自上海证券报独立引用经信委口径）**：2025 年上海软信业营业收入 **2.2 万亿元**（已站上 2 万亿元台阶）、5 年年均增速 ~15%、较 2020 年 **翻倍增长**、成为**上海第三大支柱行业**[2]。规划"2.1 万亿 → 4 万亿"以指标表呈现，而新闻通稿的 2.2 万亿口径以"营业收入"为统计口径——两者差异来自"产业规模（万亿元）"与"营业收入（万亿元）"两套统计口径，并非数据矛盾。

### 2. 18 项主要任务的结构：AI 引领 × 七大数智化 × 三大新兴赛道 × 五大支撑工程

规划共 **18 项主要任务 + 9 个专栏工程**[3][6]：

**(A) 发挥 AI 引领作用——7 个数智化跃升方向**[1][3]：
1. **互联网业数智化跃升**——电商/社交/本地生活由流量运营向价值经营转型；专栏 1 提"AI 定制消费""沉浸式社交空间""全域智能管家"。
2. **软件业数智化重塑**——**专栏 2 提出三大抓手：① "AI+工业软件百企百项"计划 ② 软件按效付费 (SaS) 模式 ③ 工业软件中试验证平台**。把 Token、数据治理、模型再训练投入纳入"企业技改支持方向"。
3. **数字内容产业数智化升级**——**专栏 3 提"多模态创作工具攻关"**；明确培育"超级个体、一人公司 (OPC)"等新生代主体。
4. **网络安全产业数智化迭代**——专栏 4 提"AI 安全产业攻关 / 安全业态焕新 / 安全语料聚沙"。
5. **智算云产业数智化转型**——**专栏 5 提"百千万智算集群工程"**：松江/临港/青浦布局**十万卡级**超大规模智算集群；宝山/浦东/嘉定布局**千卡级**智算集群；传统数据中心升级为**百卡级**边缘智算中心。
6. **金融科技产业数智化提质**——专栏 6 提数字人民币在元宇宙/供应链/RWA 资产数字化拆分。
7. **提升工业数智化转型服务能级**——**专栏 7 提"模数共振"行动 + "AI+制造"样板企业**，目标 **10 家左右"AI 原生工厂"**。

**(B) 面向未来的新兴赛道——6 个**[1][6]：
- **智能体经济**（通用智能体 / 多智能体协同 / Agent-as-a-Service）
- **AI 游戏**（剧情自生成 / 长时记忆 / 多模态交互）
- **新型终端软件**（具身智能 / 低空装备 / 脑机接口专用 OS）
- **虚拟现实（XR）**
- **原生安全**（"模型定义安全" / AI 密码 / 量子安全）
- **物理仿真 / 世界模型**（具身智能、航空航天、生物医药）

**(C) 5 个产业支撑体系**[1]：
1. 聚力 AI 技术攻关——明确"非 Transformer 架构"路线（**状态空间模型、循环神经网络变体、液态神经网络**）+ 物理智能 / 世界模型 / 量子智能 / 类脑智能前沿基础模型
2. 提升关键软件——**OS 内核 / 图形引擎 / SQL 引擎 / CAD / CAE / EDA** 底层攻关
3. 构建开源生态——专栏 9 明确支持**魔搭社区、白玉兰开源研究院、OpenLoong、OpenDataLab**等本土开源平台
4. 市场主体培育——**首次写入"出海"**：智算云 / 大模型 / 数字内容 / 软件产品技术服务出海
5. 完善平台体系——**工业语料公共服务平台 + 工业基础语料库 + 5 大类工业专业语料资源库**

### 3. "一环两极三射"产业空间布局——把 AI 产业链钉到地图上

| 层级 | 区域 | 主攻方向 |
|---|---|---|
| **一环**（中环软信业集聚发展创新环） | 杨浦长阳秀带/滨江南段、虹口金融科技国际产业园、静安市北高新区/大宁融合创新区、长宁虹桥之源/金虹桥、普陀苏河水岸经济发展带、闵行漕河泾科技绿洲 | 平台经济、数字内容、AI+金融、AI+专业服务、AI+数字生活、AI+网络安全、工业软件、AI+生产性服务 |
| **两极**（一软一硬） | **徐汇滨江**（软）+ **浦东张江**（硬） | 大模型、智能体、网络游戏、具身智能 / 智能芯片、智算服务 |
| **三射**（联动新城） | **嘉定**汽车创新港 / **青浦**市西软件园、西岑科创中心 / **松江**G60 科创云廊 | 汽车软件 / 信创、信息技术 / 产业互联网、AI+制造 |

——形成 **"中心城区服务集聚带 → 徐汇+张江创新策源地 → 嘉青松产业腹地"** 的梯次格局[1][3]。

### 5. 对工业软件企业的影响

**(A) 政策直接利好——五大抓手同时落子**

| 抓手 | 规划条款 | 对企业意味着什么 |
|---|---|---|
| **"AI+工业软件"百企百项计划** | "综合采取定向布局、揭榜挂帅、赛马制等多元化组织方式" | 国产 CAD/CAE/MES/EDA 厂商可申报专项；首版次软件推广支持力度加码[1][5] |

**(B) 市场规模与时间窗**——中商产业研究院 2026-06 数据[5]：

- **全球工业软件市场**：2024 年 5288 亿美元（+5.2%）；2025 年 5490 亿美元；2026 年预计 5767 亿美元

**(C) 工业软件与 AI 融合的具体场景**[5]：

**(D) 上海工业软件的产业空间落位**[1]：

- **松江 G60 科创云廊**（三射）—— 产业互联网 + AI+制造
- **嘉定汽车创新港**（三射）—— 汽车软件

- **国务院《关于深入实施"人工智能+"行动的意见》**[5]—— 明确"加快工业软件创新突破 + 推进工业全要素智能化发展"
- **工信部等八部门**[5]—— 到 **2027 年推出 1000 个高水平工业智能体** 的量化目标

——上海规划是国家"AI+制造"+ "国产替代"组合拳的**省级落地版**，并非孤立动作。

## What This Means

**对个人开发者**：
1. **"工具补贴 + 算力券 + 模型券"三件套**是这轮规划里最实在的红包，但申请门槛会向"超级个体 + 一人公司 (OPC)"形态倾斜——以**工作室/小微企业**注册比个人接活更易获得技改、首版次、首套算力补贴。
2. **AI Coding + Agent 工具**进入企业研发主流，意味着**"会调 Prompt + 会组合 Agent"**的开发者会比"会写业务 CRUD"的开发者拿到更高溢价；规划里明确把 **Coding 平台普及**作为软件业技改主线。
3. **超大型平台 5 → 7 家**[1] 是个温和但真实的信号：**纯依附型中小开发者**未来 5 年的天花板会变低——规划的资源明显向"自有 IP / 自有垂类模型 / 自有开发者社区"倾斜。

**对工业软件企业**：
1. **"AI+工业软件百企百项 + 首版次 + 工业软件中试验证平台"** 是这轮规划里**最值得申报**的三类专项；上海 + 全国"政府采购 20% 价格评审优惠"形成叠加红利。
2. **CAD / CAE / EDA / 操作系统 / 数据库 / 中间件**的国产替代窗口被官方明确打开——但**研发投入占比目标仅 ≥10%**[1] 意味着上海对底层技术的资金强度低于北京/深圳，**底层突破的真正窗口期不在上海**，而在北京/合肥/长沙/武汉等地的同类专项。
3. **SaS（按效付费）模式**首次写入省/市级规划文本——这是商业模式的关键拐点，但**"百企百项"的赛马制**意味着有相当部分立项可能拿不到后续资金，**企业需要在立项阶段就做出"商业化跑通"的可验证证据**，而不是等政策兜底。
4. **"出海"首次写入**[1]——意味着工业软件企业的市场评估逻辑要从 **"国产替代国内 80%"** 切换到 **"中国工业软件 + 一带一路 / 东南亚 / 中东市场"** 的双轨路径。

## Risks And Unknowns

1. **"力争达到 4 万亿"是预期性指标**[1]——并非约束性目标，与"十四五"实际增速 15% 相比，**"十五五"隐含的 13.7% 复合增速若出现 1-2 个百分点的偏差**，最终规模可能落在 3.4-3.7 万亿区间。**这是规划本身的"软"风险**[2]，与企业实际经营关系不大。
2. **研发投入占比 ≥10% 的目标偏保守**[1]——对比同类城市工业软件专项的 12-15% 目标，上海对**底层 OS / 工业软件核心引擎**的资金强度仍偏低，**关键技术突破的窗口期主要在北京/合肥/武汉而非上海**。这是**规划结构性风险**，对长期国产替代进度有直接影响。[unverified（与同类城市对比的具体数值未交叉验证）]
3. **超大型平台企业 5 → 7 家**[1]——增量只 +2 家，但规划配套有"亿级用户流量、万亿级交易平台"目标[1]——意味着 7 家中可能只有 3-4 家新晋，**议价权与 API 资源会进一步集中**，对中小开发者是真实负面。
4. **"算力作价入股 / 算力资源+应用场景招商"**[1] 是新提法，**实操层面涉及国资评估、税务、退出路径**，落地周期可能比规划目标（2026-2030）更长。
5. **"超级个体 / 一人公司 (OPC)"**[1] 的法律身份——目前我国《公司法》体系下"一人公司"已有明确规则（自然人独资），但**"超级个体"概念未在工商、税务、社保层面给出标准化定义**，规划配套实施细则预计 2027 年前才会陆续出台[1]。[unverified]
6. **百卡级 / 千卡级 / 十万卡级智算集群**[1]——实际落地节奏受国产 GPU 量产节奏、电力指标、长三角能耗双控影响，**松江 / 临港的十万卡集群可能延后至 2027-2028 年才完成部署**，而非规划默认的 2025-2030 节奏。[unverified]
7. **本调研**未访问到中国软件行业协会、上海市软件行业协会的官方解读——这两家协会通常会在规划印发后 1-2 周内发布行业解读，**可能补充"百企百项"具体名单、"百千万智算集群"选址细节**[3]。这是已知的信息空白，建议下一轮调研补充。
