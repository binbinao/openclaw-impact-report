🧬 进化建议
🔴 P0 · 修复网关重启风暴（Respawn Storm）
每日 ~99 ERROR + 99 WARNING = 198 条（39.6% 尾窗占比）。PID 3433647 连续运行 50 期（49 天），但 cron job 每次执行仍尝试启动新 gateway。修复：在 cron job 启动脚本中添加 if pgrep -f hermes.*gateway; then exit 0 前置检查。消除后可减少 39.6% 日志噪声。此建议已连续 20 期未被采纳。
🟠 P1 · 清理无效 plugin.json 文件
每日 294 条 WARNING（58.8%）。三个签名完全一致：.cursor-plugin、.claude-plugin、.codex-plugin 的 plugin.json 声明不被支持。修复：删除 ~/.hermes/profiles/reviewer/plugins/superpowers/ 下的这三个目录。消除后可将日志噪声减少 58.8%。
🟠 P2 · 配置 API_SERVER_KEY 或禁用 api_server
每日 6 条 ERROR，每 5 分钟一次。修复：在 config.yaml 中设置 API_SERVER_KEY 或将 api_server 平台配置注释掉。
🟡 P3 · 修复 approvals.mode 配置
在 config.yaml 中将 approvals.mode 从 'auto' 改为 'manual'、'smart' 或 'off'。
🔵 P4 · 启用备选学术数据源
arXiv API 自 P74 以来 20 期中仅 10.0% 成功。P89→P93 连续 5 期失败，追平历史第二长纪录。建议启用 Semantic Scholar API（free tier 100 req/day）或 CrossRef API 作为备选。
⚪ P5 · 升级 weakness_scan.py 以修复三重盲区
盲区已连续 53 期（>4.4 个月）。建议：(a) 添加 WARNING 级别聚合检测规则，(b) 跨组件签名聚合，(c) 全文件周期扫描模式替代仅尾窗 500 行策略。
