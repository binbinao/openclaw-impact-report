一、巴威（Bavi）台风基本信息

参数数值
国际编号2008（2020年第8号台风）
活跃时间2020年8月21日 — 8月27日
巅峰强度强台风级（~950hPa，最大风速 45m/s）
影响区域东海 → 朝鲜半岛 → 中国东北
需要下载的ERA5时间范围2020-08-20 至 2020-08-28（覆盖整个生命周期）

二、下载 ERA5 数据的 CDS API 脚本

# 1. 安装 CDS API
pip install cdsapi

# 2. 下载脚本 (download_era5_bavi.py)
import cdsapi

c = cdsapi.Client()

# 下载高度层变量 (37层 × 5变量)
c.retrieve('reanalysis-era5-pressure-levels', {
    'product_type': 'reanalysis',
    'variable': [
        'geopotential',
        'specific_humidity',
        'temperature',
        'u_component_of_wind',
        'v_component_of_wind',
    ],
    'pressure_level': [
        '1','2','3','5','7','10','20','30','50','70',
        '100','125','150','175','200','225','250','300','350','400',
        '450','500','550','600','650','700','750','775','800','825',
        '850','875','900','925','950','975','1000',
    ],
    'year': '2020',
    'month': '08',
    'day': [str(d) for d in range(20, 29)],
    'time': ['00:00', '06:00', '12:00', '18:00'],
    'format': 'netcdf',
}, 'era5_plevels_bavi.nc')

# 下载地表变量
c.retrieve('reanalysis-era5-single-levels', {
    'product_type': 'reanalysis',
    'variable': [
        '2m_temperature',
        '10m_u_component_of_wind',
        '10m_v_component_of_wind',
        'mean_sea_level_pressure',
    ],
    'year': '2020',
    'month': '08',
    'day': [str(d) for d in range(20, 29)],
    'time': ['00:00', '06:00', '12:00', '18:00'],
    'format': 'netcdf',
}, 'era5_surface_bavi.nc')

三、数据预处理关键步骤

步骤操作注意事项
1. 分辨率对齐 插值到 0.25° 网格（721×1440） ERA5 原生就是 0.25°，但下载后需确认经纬度维度正确
2. 变量归一化 按 GraphCast 预训练统计量做 Z-score normalization 必须使用 GraphCast 官方提供的 stats 文件，不能用自己算的均值/标准差
3. 变量拼接 将 37 层×5 变量 + 地表×4 变量拼接为 189+4=193 通道 加上静态变量（地形、land-sea mask）和年/日时间特征，最终 ~252 通道
4. 时间窗口切片 每个样本取 (t-6h, t) 两个时刻作为输入 注意：第一个可用时刻 t=08-20 00:00（需要 t-6h 数据），必要时延长下载范围

四、快速上手：使用官方 Demo 代码

# 克隆 GraphCast 仓库
git clone https://github.com/google-deepmind/graphcast.git
cd graphcast

# 下载预训练模型和统计文件
# 从 https://console.cloud.google.com/storage/browser/dm_graphcast
# 下载: params/GraphCast_small - ERA5 1979-2017 - resolution 1.0 - pressure levels 13 - mesh 2to5 - precipitation input and output.npz
# 下载: stats/diffs_stddev_by_level.nc 和 mean_by_level.nc

# 运行推理
python graphcast_demo.py \
  --input_plevels era5_plevels_bavi.nc \
  --input_surface era5_surface_bavi.nc \
  --start_time 2020-08-24T00:00 \
  --lead_time 72

五、常见坑

坑解决办法
CDS 下载限速/排队提前几天申请，1个月×全球×37层数据量约 150-200GB，下载可能需要数小时
模型分辨率不匹配GraphCast 官方提供 0.25°（高精度）和 1.0°（快速）两个版本。台风仿真建议用 0.25°
气压层数量不匹配官方预训练模型使用 13 层或 37 层。37 层版本精度更高但推理更慢
归一化统计文件错误必须从官方 GCS 桶下载 stats 文件，自己算的统计量会导致模型输出完全错误
显存不够0.25° 全局推理需要 ~16GB 显存。可以裁剪东亚区域（但 GraphCast 原生不支持区域推理，需要修改代码）
