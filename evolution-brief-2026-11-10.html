本期新立规则

DZ

占用率与 ETA 互为函数，不得同表各给一个

ETA = 阈值×(1−p) ÷ rate。同一文件的百分比与 ETA 相差 >20% 即自相矛盾。P165 #7 的 71% 偏差是首个实证。

EA

快拒 / 快成的分界是配额窗口，不是请求形状

3/3 429 @0.7–1.0 s 之后 5/5 200 @0.39–0.43 s（同 UA、同 URL）⇒ 单发失败不可归因形状。协议只改延迟（https 0.89× 阈值）。

EB

轮转不重置连胜，但连胜必须并读归档

现档 1.0 日 + 归档末 ERROR 10-23 = 18.0 日。轮转清现档证据，不清归档证据（CD / BW 的时间维）。

快照与口径：本报告所有计数取自 2026-11-10 09:07:59 CST 的实测（reviewer errors.log 22,709 B / 143 记录为该时点值，落盘过程中仍在增长 —— 本期本会话自身写入约 3 KB，占现档 13%，属规则 N 的观察者分量）。ERROR 口径为 <LEVEL> (\[tag\] )?<logger>: <msg> 解析出的级别字段，非正文子串（规则 BY）。现档合计 = 7 个 profile 的 errors.log 当前文件逐条解析之和；冻结 profile 按「末记录 2026-09-15 08:11–08:12 + mtime」判活后单列（规则 BE）。
