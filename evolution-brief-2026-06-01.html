🧬 进化建议

🔮 基于 5 期数据的改进方向：
  1. 🔴 紧急: 修复安全审批阻塞（tool_executor 恶化） — agent.tool_executor 连续 3 期恶化（19→25→36），pending_approval 和 '&' 背景化拦截已成最大动态风险。建议：
    a) 将 scripts/ 目录加入安全白名单
    b) 在 cron job 中强制使用 execute_code 替代 terminal
    c) 配置安全策略允许预批准的终端命令模式
  2. 🔴 紧急: 配置 fallback provider 应对 API 不稳定 — 连续 3 期出现 API 问题（429/超时交替），deepseek-v4-flash via TokenHub 稳定性不可靠。建议配置备用 provider 或模型，确保 cron job 在 API 限频时仍可运行。
  3. 🟡 切换 arXiv 备选源 — 连续第 5 期失败，已排除间歇性问题。建议更新 knowledge_ingest.py：
    a) 添加 arXiv Sanity Lite (https://arxiv-sanity-lite.com/) 作为主要备选
    b) 添加 Semantic Scholar API 作为第二备选
    c) 允许 fallback 链（arXiv → Sanity → SS → 空）
  4. 🟡 移除未使用的 Discord 适配器 — 连续 5 期点名，54 条/天的无用错误。从 config.yaml 移除 discord_platform 可减少 14% 的日志噪声。属于低挂果实。
  5. 🟢 关注 AI 安全边界趋势 — 本期 HN 头条 Cloudflare Turnstile 指纹识别 + Codex sudo workaround 安全讨论，都指向 AI Agent 操作安全边界的热点问题。与 Hermes 的 pending_approval 策略直接相关。
  6. 🟢 评估 1-Bit Bonsai 图像模型 — 4B 参数的 1-bit 图像生成模型可在本地设备运行，可作为 Hermes image_gen 备选方案评估。
