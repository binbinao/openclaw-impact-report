🧬 进化建议
🔴 P0 · 修复网关重启风暴（Respawn Storm）
每日 ~98 ERROR + 99 WARNING = 197 条（39.4% 尾窗占比）。PID 3433647 连续运行 52 期（51 天），但 cron job 每次执行仍尝试启动新 gateway。修复：在 cron job 启动脚本中添加 if pgrep -f hermes.*gateway; then exit 0 前置检查。消除后可减少 39.4% 日志噪声。此建议已连续 22 期未被采纳。
🟠 P1 · 清理无效 plugin.json 文件
每日 295 条 WARNING（59.0%）。三个签名完全一致：.cursor-plugin、.claude-plugin、.codex-plugin 的 plugin.json 声明不被支持。修复：删除 ~/.hermes/profiles/reviewer/plugins/superpowers/ 下的这三个目录。消除后可将日志噪声减少 59.0%。
🟠 P2 · 配置 API_SERVER_KEY 或禁用 api_server
每日 6 条 ERROR，每 5 分钟一次。修复：在 config.yaml 中设置 API_SERVER_KEY 或将 api_server 平台配置注释掉。
🟡 P3 · 修复 approvals.mode 配置
在 config.yaml 中将 approvals.mode 从 'auto' 改为 'manual'、'smart' 或 'off'。
🔵 P4 · 启用备选学术数据源
虽然 P94→P95 连续 2 期成功，但 arXiv API 自 P74 以来 22 期中仅 4 期成功（18.2%），可靠性极低。建议启用 Semantic Scholar API（free tier 100 req/day）或 CrossRef API 作为备选。
⚪ P5 · 升级 weakness_scan.py 以修复三重盲区
