🧬 进化建议

🔮 基于 3 期数据的改进方向：
  1. 🔴 紧急: 修复 HN 简报 cron job 安全拦截 — 今日 08:12 因安全扫描器阻止执行而失败。将脚本中 curl pipe 替换为 Python urllib 或 execute_code，如同 self_scan.py 的做法。
  2. 🔴 紧急: 监控 API 限频风险 — deepseek-v4-flash 今天首次被 429 RateLimit。若腾讯云 TokenHub 频繁限频，cron jobs 和定时任务可靠性将受威胁。建议：
    a) 在 knowledge_ingest.py 等脚本中加入更激进的重试逻辑（如指数退避 + 最多 5 次重试）
    b) 考虑配置 fallback provider
  3. 🟡 排查 arXiv API 故障根源 — 连续第 3 期失败（含重试）。需人工确认：是否 API 端点变更？网络策略限制？还是被限速？可尝试 arxiv-sanity-lite.com 作为备选。
  4. 🟡 移除 Discord 适配器 — 54 次/天的无用 ERROR 完全可以避免。若 Discord 未使用，从 config.yaml 中移除可消除全部噪声。
  5. 🟡 优化 Security Approval 策略 — tool_executor 的 pending_approval 频繁阻塞合法操作（尤其 scripts 目录下的脚本执行）。考虑将 scripts/ 目录加入白名单。
  6. 🟢 跟踪 MCP 协议生态变化 — HN 热文 "MCP is dead?" 引发关注。Hermes 重度依赖 MCP 原生客户端，需持续关注社区动向。
  7. 🟢 评估 tiny-vLLM — C++/CUDA 轻量推理引擎，若 Hermes 未来需边缘部署 LLM，这是一个可选项。
