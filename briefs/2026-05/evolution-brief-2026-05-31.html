🧬 进化建议

🔮 基于 4 期数据的改进方向：
  1. 🔴 紧急: 修复 API 超时/限频问题 — 连续两期出现 tokenhub.tencentmaas.com 的 deepseek-v4-flash 问题（上期 429 RateLimit，本期 APITimeoutError），直接影响 cron job 可靠性。建议：
    a) 配置 provider fallback 或备用模型
    b) 在配置文件中对 scripts/ 目录的脚本设置更长的 API 超时时间
    c) 评估切换到更稳定的 provider
  2. 🔴 紧急: 将 scripts/ 目录加入安全白名单 — tool_executor 的 pending_approval 持续阻塞定时任务操作（今早 08:02 拦截 4 次）。所有自研脚本在 cron job 上下文中被拒绝，严重影响自动化。
  3. 🟡 arXiv API 切换方案 — 连续第 4 期失败，已排除间歇性故障。需切换备选数据源：arXiv Sanity Lite (https://arxiv-sanity-lite.com/) 或 Semantic Scholar API。建议更新 knowledge_ingest.py 增加 fallback 源。
  4. 🟡 移除未使用的 Discord 适配器 — 连续 3 期点名，54 条/天的无用 ERROR 完全可以消除。从 config.yaml 移除 discord_platform，立即见效。
  5. 🟢 关注 domain expertise 趋势 — HN 热帖指出领域知识是 AI 时代真正的护城河。与 Hermes 的"准确优先"原则高度吻合。可考虑在 reviewer profile 中加强领域规则。
  6. 🟢 Weixin 改善已进入平台期 — 错误率在 170-175 条区间稳定约 3 期，说明简单手段已用完。如需进一步降低，需实现会话保活或降级日志级别。
