🔴 优先级 1：修复 gateway.run 洪水（已持续 39 期）

PID 3433647 已连续运行 18 天（19 期）。每次 cron job 执行时尝试启动新 gateway 实例失败，产生 97.6% 的错误日志。全文件 4,014 条（96.5%）来自同一签名。修复命令：cd /root/.hermes/profiles/reviewer && hermes gateway stop && hermes gateway start。此修复估计可消除 95%+ 的错误日志，恢复系统健康度。

🟡 优先级 2：修复两个配置错误

1. api_server 配置（83 条/天）：API_SERVER_KEY 缺失。在 config.yaml 中配置 API 密钥或禁用 API 服务器。
2. tools.approval 配置（48 条/天）：approvals.mode: 'auto' 无效。设为 manual、smart 或 off。此配置错误修复后，非洪水基线可降至 ~15 条/天。

🔵 优先级 3：weakness_scan.py 修复

三重盲区已连续 22 期。建议修复：
  1. 添加全文件扫描模式（遍历整个日志文件而非仅尾部 500 行）
  2. 添加 WARNING 级别聚合检测（同一签名 ≥10 次视为 medium 弱点）
  3. 添加跨组件签名聚合规则（配置错误类错误跨组件求和）

🟢 优先级 4：技能清理

技能 55/67（82%）标记为 stale。建议清理过期技能、归档不再使用的技能、合并重复技能。可释放约 50 个技能槽位。
